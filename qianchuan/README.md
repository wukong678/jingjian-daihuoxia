**素材会衰退，产能不衰退——巨量千川投手的素材弹药库。**

投剪·千川侠是面向巨量千川投手与电商投放团队的**跑量素材批量制作与去重工具**，按投放漏斗（起量期钩子测试 → 放量期多版本 AB → 衰退期自动补量）组织素材生产：AI 分镜脚本、原生素人口播、画面差异化渲染、素材同质化检测，一条源素材批量产出 N 个去重变体。

## 功能速览

- **AI 分镜脚本**：按「3 秒钩子 → 卖点展开 → 促单引导」结构生成原生素人感口播
- **钩子批量变体**：痛点/价格/悬念/反差四类钩子结构，同一卖点多个 3 秒开头对赌跑量
- **原生素人口播配音**：TTS 多音色多语速，口语化停顿处理，拒绝机器朗读腔
- **差异化渲染引擎**：运镜/转场/节奏/字幕/BGM 五维随机组合，批量变体逐条不同
- **素材同质化检测**：成片指纹比对历史素材，重合率超阈值自动重新编排
- **千川审核合规清洗**：绝对化用词、极限词、资质表述自动检测重写
- **投放规格输出**：1080×1920 竖屏 30fps，双层渲染字幕文字完整不裁切

## 为什么能防同质化限流

千川对同质化素材限流的前提是"素材相似"。投剪·千川侠从内容指纹层面产出真正不同的成片：

1. **文案层**：AI 逐条生成或语义重写（语义不变、表述全换），违禁词自动清洗
2. **画面层**：叙事顺序重排 + 五维画面随机组合再渲染
3. **检测层**：成片与历史素材指纹比对，超阈值自动重新编排后输出
