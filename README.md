# 简介

京剪·带货侠是一款面向 **京东内容创作者、带货达人与电商运营团队** 的 **AI 商品视频生成 + 自动发布** 一站式工具。把「**佣金选品 → 商品素材采集 → AI 选图 → AI 口播文案 → TTS 配音 → 竖屏视频渲染 → 自动发布京东**」的整条链路搬进一个软件，粘贴一个京东商品链接，软件自动完成选品校验、素材下载、AI 创作、成片渲染与发布，全程无人值守。

一条商品视频，从链接到发布，**全程不需要你打开任何剪辑软件**。

## 什么是京东商品视频带货

在京东App的内容频道与商品详情页里，**短视频已经是最重要的种草与转化载体**：带视频的商品详情页停留更久、转化更高。但手工做一条商品视频，选图、写文案、配音、剪画面、上传发布，一条就要一两个小时，做十个商品一天就没了。

**京剪·带货侠要解决的就是这个产能问题**：京东内容平台的视频判重很严，同素材、同结构的视频会被判定重复内容不予推荐，画面不清晰、文字被裁切还会被判劣质。软件在生成端就针对这些规则做了专门设计——AI 选图只用商品本体干净实拍图、双层运镜保证画面文字绝不半出屏、口播文案自动规避绝对化用词、同款商品自动去重、素材雷同的变体商品只发一条，**让批量生成的每一条视频都尽量是"原创的、干净的、完整的"**。

## 功能详解

### 全自动模式（无人值守）

- 一次配置抓取数量与佣金门槛，软件自动完成 **选品 → 采集 → 生成 → 发布** 全流程。
- 批次内每条任务状态实时可见：待处理 / 采集中 / 生成中 / 发布中 / 已发布 / 失败。
- 单条失败自动跳过不阻塞批次，带视频素材的商品优先处理。
- 生成后自动发布可关，先攒着人工审一遍再发也行。

### 素材采集（干净的全量素材）

- 自动解析商品详情页，下载主图、详情长图、主图视频，商品信息与素材分商品归档。
- 采集全程携带来源标识模拟真人从首页/搜索进入，条与条之间随机间隔歇息。
- 素材库支持按商品浏览、多选删除、随时回看原始素材。

### AI 选图与画面编排（只上干净的商品图）

- AI 分批看图给每张图打标签：商品本体 / 使用场景 / 包装盒 / 参数表 / 平台设计图。
- 只允许商品本体与使用场景图进片，其余**程序端强制剔除**，AI 说了不算。
- 本地 OCR 再兜一层底：图里带平台品牌字样的图直接拦下。
- 主图自动前置——观众 3 秒内一眼认出卖的是什么。
- 口播文案与画面槽位按维度轮换，避免每条视频念得一模一样。

### 视频渲染（为过审而设计的画质）

- 1080×1920 竖屏 30fps，Kan Burns 动态运镜 + 多种转场随机组合。
- 双层渲染架构：前景商品图完整显示不裁切，背景做深度模糊处理，画面文字绝不半出屏。
- 时间轴算法保证语音绝不截断，节奏按"开头快切抓眼球、结尾放慢落幅"自动编排。
- 支持 BGM、淡入淡出、字幕样式配置。

### 自动发布与数据管理

- 成片自动填标题发布到京东内容平台，发布间隔随机化，模拟真人发布节奏。
- 已发布记录可清除重抓、可重新生成，发布去重池防止同一商品重复发布。
- 成片文件一键打开所在位置，网页内直接预览播放。

## 工作原理

1. **选品入队** ：按佣金比例抓取选品列表，规则 + AI 语义双重同款去重后批量入队。

2. **素材采集** ：逐个打开商品详情页，下载主图 / 详情图 / 主图视频，商品信息全量入库。

3. **AI 创作** ：AI 看图挑选干净的商品本体图，AI 撰写口播文案并生成标题。

4. **渲染成片** ：TTS 配音 → 双层运镜渲染 → 混剪视频片段 → 字幕与 BGM 合成，1080×1920 竖屏成片。

5. **自动发布** ：标题话题自动填充，发布到京东内容平台，全程模拟真人节奏。

6. **批次回流** ：每条任务状态与结果落库，成功可复盘、失败可重试、素材可复用。

## 底层技术特性

为什么它生成的视频更"耐审"，为什么它能长时间稳定无人值守。

- **判重防御**：同款去重（标题规则 + AI 语义分组）+ 素材指纹比对（感知哈希图库重合率闸门）+ 口播文案逐条生成，三层机制让每条成片内容差异化。
- **判劣质防御**：双层运镜架构保证画面文字完整不出屏，背景销字处理不留模糊残痕，AI 选图白名单杜绝包装盒/参数表上镜。
- **风控防御**：真实浏览器环境 + 来源跳转伪装 + 采集/发布随机间隔与长歇 + 拟人化输入，全链路降低自动化特征。
- **渲染管线**：FFmpeg 多进程渲染，深度估计模型批量单进程加载，长批次不降速。
- **容错设计**：失败熔断、自动跳过、断点续跑、风控冷却后手动续抓，长批次跑不完也不丢进度。

## 常见问题（FAQ）

**Q：一条视频需要人工干预吗？** A：全自动模式下不需要。粘贴商品链接或设定抓取数量后，采集、AI 创作、渲染、发布自动完成；也可以关掉自动发布，人工审片后再发。

**Q：生成的视频会被平台判重复吗？** A：软件从三个层面做差异化：同款商品自动去重（AI 语义识别）、素材雷同的商品自动拦截（图库指纹比对）、口播文案逐条 AI 生成。同一条商品的素材也可以反复生成不同风格的成片。

**Q：AI 选图会不会选到包装盒、参数表？** A：不会。AI 逐张看图分类后，程序端做白名单硬校验强制剔除，另有一层本地 OCR 识别兜底，规则不由 AI 说了算。

**Q：视频里的文字会被裁切吗？** A：不会。渲染采用双层架构：商品图完整显示在前景，动态运镜只发生在模糊背景层，画面文字始终完整。

**Q：一天能处理多少商品？** A：取决于商品数量与素材规模，正常网络下无人值守可稳定处理数十个商品；采集与发布节奏做了拟人化随机间隔，宁稳勿快。

**Q：支持免费试用吗？** A：软件采用邀请制，请添加客服获取安装包与激活方式。
