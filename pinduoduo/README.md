## 功能速览

- **多多进宝佣金选品**：按佣金与销量门槛批量抓取，低佣低质自动过滤
- **商品素材自动采集**：主图 / SKU 图 / 详情图 / 主图视频全量归档复用
- **促销角标 AI 清理**：AI 逐张看图剔除"拼多多/百亿补贴/秒杀"类横幅角标图，另加本地 OCR 兜底
- **AI 口播 + 多音色配音**：口播脚本逐条生成不重样，违禁词自动检测重写
- **差异化去重引擎**：运镜、转场、节奏、BGM、封面、口播六维随机组合，批量产出差异化变体
- **同款商品智能去重**：标题规则 + AI 语义识别同款不同 SKU，只留佣金最高的一条
- **图视频智能混剪**：主图视频自动抽片段混剪，纯图商品双层运镜渲染
- **多多视频自动发布**：标题话题自动填充，拟人节奏发布，批次可视化跟踪

## 为什么能防判重

多多视频的原创度检测对"同素材反复发"很敏感。多剪·带货侠从生成端做三层差异化：

1. **文案层**：AI 按商品卖点逐条生成口播，每条视频念的都不一样
2. **画面层**：运镜/转场/节奏/BGM/封面六个维度逐条随机组合
3. **源头层**：图库指纹比对，素材高度雷同的变体商品直接跳过不发
